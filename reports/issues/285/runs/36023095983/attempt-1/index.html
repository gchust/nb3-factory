建议 01 · process

Smoke-test page tasks conflict with the mandatory full UI workflow

需人工判断

The frontend workflow (references/frontend/ui-workflow.md) classifies any new page as a full workflow requiring a design file, design review and independent acceptance review. Factory smoke-test tasks such as F00 explicitly ask for a minimal page with no style refinement and no extra process, so the two instructions disagree on the required overhead.

建议改动

Add a short exception in ui-workflow.md: when a task explicitly declares itself a pipeline/acceptance smoke test or similar minimal verification page, the quick-change path applies even though it is a new page; the task statement is the authority.

来源：Agent · retro.json

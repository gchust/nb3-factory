建议 01 · framework

Template ships an AGENTS.md that fails format:check

可自动化

The committed AGENTS.md has a double blank line from commit e318f4e. Because format:auto only rewrites task-changed files, every task in this generated application starts with a whole-repo format:check failure unrelated to the task, and verify.sh aborts before lint/typecheck/test.

建议改动

Ship AGENTS.md already prettier-clean in the template (or add AGENTS.md to .prettierignore), so the baseline format:check passes for a task that touches no markdown.

来源：Agent · retro.json

建议 02 · framework

format:auto normalizes only changed files while format:check checks the whole repository

可自动化

The mismatch between the auto-fix scope (git diff HEAD + untracked) and the check scope (prettier .) means pre-existing formatting drift in any tracked file can never be auto-repaired, only surfaced as a failure the agent must interpret and fix by hand.

建议改动

Either have format-changes.mjs also normalize tracked files that format:check would reject, or scope the check to the changed set; at minimum report a baseline formatting failure separately from task-caused failures.

来源：Agent · retro.json

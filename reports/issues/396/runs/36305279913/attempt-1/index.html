实际操作

  1. 打开 http://127.0.0.1:13000/main/ 并用 admin 账号登录，登录后离开 login 页进入业务主页
  2. 英文界面检查标题 Build Pipeline Verification、说明 Requirement from TestManage3，以及 Notes 按钮 expanded=false
  3. 点击 Notes 按钮展开，读取展开后的文本，再次点击收起并确认 expanded=false
  4. 通过右上角账户菜单 → Language English → 中文 切换为中文，等待应用重新加载
  5. 中文界面检查标题“搭建链路验证”、说明“需求来自 TestManage3”，以及“说明”按钮 expanded=false
  6. 点击“说明”展开，读取文本，再次点击收起并确认 expanded=false
  7. 检查 console 日志、page errors 与网络请求状态码

观察结果

  1. 英文：标题 “Build Pipeline Verification”，说明 “Requirement from TestManage3”，Notes 按钮 expanded=false（默认收起）
  2. 英文：点击 Notes 后 expanded=true，显示 “The requirements added in the comments are included in this build.”，再次点击后 expanded=false 且文本消失
  3. 中文：标题 “搭建链路验证”，说明 “需求来自 TestManage3”，“说明”按钮 expanded=false（默认收起）
  4. 中文：点击“说明”后 expanded=true，显示 “评论追加的需求已包含在本次搭建中”，再次点击后 expanded=false 且文本消失

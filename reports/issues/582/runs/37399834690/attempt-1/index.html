建议 01 · workflow-guidance

Frontend 'full workflow' mandates a design/review/screenshot process that the factory smoke task explicitly forbids

可自动化

The ui-workflow reference classifies any new page as 'full workflow', requiring storage/ui-workflow/<feature> design.md, an independent design review, browser screenshots and an acceptance review. This task is an intentionally trivial pipeline smoke test and explicitly states that screenshots, reports and QA are factory-owned and that no style refinement or architecture work is expected. Following the skill literally would create throwaway artifacts and reviewer subagents for a 30-line counter page.

建议改动

Add a documented 'trivial/smoke page' scope to the ui-workflow selection table (e.g. a page with no data, no new interaction beyond local state, and no route structure change) that allows direct implementation plus focused static checks and component tests, and record that this task scope overrides the full workflow in the task instructions.

来源：Agent · retro.json

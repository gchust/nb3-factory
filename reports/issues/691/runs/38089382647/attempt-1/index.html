原因（实现者自述）

建议 01 · 工具与构建

shadcn CLI output fails the repository quote rules until formatted

可自动化

The shadcn CLI writes double-quoted TypeScript that eslint's configured quotes and jsx-quotes rules reject, so every newly added primitive fails scoped lint until prettier runs.

建议改动

Have the add-primitive workflow run prettier --write on the primitive immediately (the development Skill already says to format the file; making it an explicit lint-blocking step would save a round trip).

来源：Agent · retro.json

建议 02 · documentation

Demonstration data runs at server ready(), not on db apply

需人工判断

A database that has only had migrations and seeds applied has the permission sets but no demo customers/devices/orders until the application starts once.

建议改动

State in the server notes that demo data is created at ready() and that db apply alone is not enough; if acceptance expects rows immediately after db apply, move the dataset to a seed.

来源：Agent · retro.json

建议 03 · testing

API-document test caught a missing 409 response code

可自动化

findApiDocumentSchemaProblems rejected the accept route until the declared 409 response was listed.

建议改动

Keep findUndeclaredApiRoutes and findApiDocumentSchemaProblems in the standard route test; they catch declaration drift cheaply.

来源：Agent · retro.json

建议 04 · documentation

Workflow handlers are not ordinary server modules

需人工判断

A handler runs from a materialized artifact under storage/workflows, so relative imports to server/ or to sibling handlers fail after Node type stripping; the failure appears only at run time.

建议改动

State in the Workflow guidance that a handler must be self-contained, import only types, and reach application services through a global token published by Symbol.for, not a relative import.

来源：Agent · retro.json

建议 05 · testing

AI resources can be asserted without a model

可自动化

Resolving aiManagerToken in a started app lets a test check the registered employee and tool, and invoking the tool with a hand-built AgentContext proves the authorization scoping without any LLM service.

建议改动

Keep an AI-resources test that resolves aiManagerToken, asserts the employee and tool, and invokes the tool as a permitted and a denied caller.

来源：Agent · retro.json

建议 06 · environment

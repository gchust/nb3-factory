实际操作

  1. 访问 $FACTORY_BROWSER_URL，使用已有管理员测试账号 nocobase 登录，离开登录页进入 /main 业务界面
  2. 点击顶部导航栏中的 “Pipeline Smoke” 链接，真实跳转到 http://127.0.0.1:13000/main/pipeline-smoke
  3. 读取页面内容确认标题 “Pipeline Smoke”、说明 “Used to verify the automated build pipeline.”、初始计数值 Count 0 与 “+1” 按钮
  4. 点击 “+1” 按钮，重新读取页面确认计数值变为 Count 1
  5. 刷新页面后确认计数回到 Count 0（计数仅存在于当前页面内存）
  6. 检查页面错误与控制台：errors 与 console 均无内容

观察结果

  1. 登录后业务界面导航栏存在 “Pipeline Smoke” 入口，点击后 URL 为 /main/pipeline-smoke
  2. 页面标题为 “Pipeline Smoke”，说明为 “Used to verify the automated build pipeline.”
  3. 初始读取内容为 “Count0+1”，即初始值 0
  4. 点击 +1 后读取内容为 “Count1+1”，即计数值为 1
  5. 刷新后读取内容为 “Count0+1”，计数归零，符合页面内存计数的要求
  6. 无页面错误、无未处理异常、无 4xx/5xx 或 Something went wrong

建议 01 · template

Make the string-id requirement for per-record sharing explicit

可自动化

The authorization layer's record selection schema only accepts string ids, so any Collection that should support Sharing Rules must use a string primary key. An integer primary key builds, boots and serves normally, then fails a share with a 400 INVALID_FILTER that names only the field type.

建议改动

Document this at the Sharing Rules reference and at the Collection builder, or coerce/validate selection ids against the target field type when a rule is created.

来源：Agent · retro.json

建议 02 · 工具与构建

Warn when a granted composite action has no database policy branch

可自动化

A composite authorization decision can be `conditional` with no policy for the configured collection, and the route then has to invent a per-action denial. A boot-time validation could report a composite action whose grants never produce a database condition.

建议改动

Extend the authorization startup checks to report composite actions with no reachable database policy.

来源：Agent · retro.json

建议 03 · 工具与构建

Refresh the lockfile after correcting shadcn's package.json edits

可自动化

The shadcn add workflow writes pnpm-lock.yaml itself, pinning @nocobase/i18n to an exact version and adding client-only packages under importer dependencies. The documented correction is to restore the ^ range and move the package to devDependencies in package.json, but the lockfile is then stale and every later frozen-lockfile install fails with ERR_PNPM_OUTDATED_LOCKFILE.

建议改动

State in the shadcn reference that after editing package.json the lockfile must be regenerated with `pnpm install --no-frozen-lockfile`, or have the CLI leave the lockfile to the next install.

来源：Agent · retro.json
